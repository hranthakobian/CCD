# Օրացույցի Ստեղծիչ (CCD)

«Օրացույցի Ստեղծիչ»-ը նախատեսված է Adobe InDesign-ում բարձրորակ, տպագրական չափանիշներին համապատասխան օրացույցներ ավտոմատ ստեղծելու համար: Հավելվածն աշխատում է ինչպես CEP (Common Extensibility Platform), այնպես էլ UXP (Unified Extensibility Platform) միջավայրերում՝ ապահովելով արագագործություն, ճկունություն և դիզայնի լիարժեք վերահսկողություն:

---

## Հիմնական հնարավորություններ

### 1. Օրացույցի ճկուն գեներացում
- 12 ամիսների միաժամանակյա ստեղծում առանձին 12 էջերում կամ միայն մեկ ընտրված ամսվա գեներացում (1 էջ):
- Տարեթվի ընտրության լայն միջակայք՝ 1900-ից մինչև 2100 թվական:
- Շաբաթվա սկզբի ընտրություն՝ Երկուշաբթի կամ Կիրակի:
- Վերնագրերի (ամիս և տարի) և շաբաթվա օրերի տողի անջատման/միացման հնարավորություն:
- Նախորդ և հաջորդ ամիսների լրացնող օրերի (padding days) ցուցադրում:

### 2. Բազմալեզու աջակցություն (12 լեզու)
Օրացույցի ամիսների և շաբաթվա օրերի անվանումները հասանելի են 12 լեզվով.
- Հայերեն (Արևելահայերեն)
- Հայերեն (Արևմտահայերեն)
- Անգլերեն (English)
- Ռուսերեն (Русский)
- Ֆրանսերեն (Français)
- Գերմաներեն (Deutsch)
- Իսպաներեն (Español)
- Իտալերեն (Italiano)
- Պորտուգալերեն (Português)
- Վրացերեն (ქართული)
- Հունարեն (Ελληνικά)
- Լեհերեն (Polski)

Փլագինի ինտերֆեյսն ունի հայերեն և անգլերեն լեզուների արագ փոխարկիչ:

### 3. Տոների և հիշարժան օրերի հաշվարկ
- Պետական (անշարժ) և եկեղեցական/ազգային (շարժական) տոների ավտոմատ ճշգրիտ հաշվարկ:
- Աջակցվող երկրներ և տարածաշրջաններ՝
  - Հայաստան (ՀՀ պետական տոներ և Հայ Առաքելական եկեղեցու շարժական տոներ՝ Զատիկ, Համբարձում, Վարդավառ և այլն)
  - Ռուսաստան (պետական և ուղղափառ շարժական տոներ)
  - ԱՄՆ (դաշնային և շարժական տոներ)
  - Ֆրանսիա (ազգային տոներ)
  - Գերմանիա (ազգային տոներ)
  - Վրաստան (պետական և ուղղափառ տոներ)
  - Եվրոպա / Միջազգային տոներ
- Տոների անվանումների տեղադրում անմիջապես օրացույցի վանդակում (In-cell holiday text):
- Ամսվա տոների ամփոփ տակագիր (Footer caption) էջի ստորին հատվածում:

### 4. Չափսեր, դիրքավորում և միավորներ
- Չափման միավորներ՝ միլիմետր (mm), սանտիմետր (cm), պունկտ (pt), դյույմ (in), պիքսել (px):
- «Վերցնել էջից (Auto)» ֆունկցիա՝ ակտիվ փաստաթղթի չափսերի և լուսանցքների (margins) ավտոմատ սինքրոնացման համար:
- Աղյուսակի լայնության, բարձրության, ինչպես նաև X և Y լուսանցքների կարգավորում:
- Բջիջների ներքին հեռավորության (Cell Padding X/Y) և եզրագծերի (Stroke/Margin) ճշգրիտ կառավարում:
- 9-կետանոց դիրքավորման մատրիցա (Reference Point Grid)՝ բջջի ներսում տեքստի դիրքը որոշելու համար (վերև-ձախ, կենտրոն, ներքև-աջ և այլն):

### 5. Տառատեսակներ և տպագրություն (Typography)
- Առանձին տառատեսակի և չափսի (pt) ընտրություն հետևյալ տարրերի համար՝
  - Ամսվա և տարվա վերնագիր
  - Շաբաթվա օրերի անվանումներ
  - Աշխատանքային օրերի թվեր
  - Շաբաթ և կիրակի օրերի թվեր
  - Հարևան ամիսների թվեր
- Նախապես ներառված են հայկական և միջազգային տարածված տառատեսակներ (Calibri, Arial, Sylfaen, Noto Sans Armenian, GHEA Grapalat, GHEA Mariam, Tahoma, Segoe UI, Times New Roman, Myriad Pro, Minion Pro):

### 6. Գույներ և ոճավորում
- HEX կոդերով տեքստի և ֆոնի (Fill) առանձին կարգավորումներ՝
  - Վերնագրի տող
  - Շաբաթվա օրերի տող
  - Աշխատանքային օրերի բջիջներ
  - Շաբաթ և կիրակի օրերի բջիջներ
  - Հարևան ամիսների բջիջներ
  - Պետական տոների բջիջներ
  - Շարժական տոների բջիջներ
- Ներկառուցված արագ գունապնակ (Swatches) և ավտոմատ InDesign Swatches-ի ստեղծում փաստաթղթում:

## Տեղադրում

### Տարբերակ 1. Ավտոմատ տեղադրում Windows-ում (Խորհուրդ է տրվում)

1. Փակեք Adobe InDesign ծրագիրը:
2. Ներբեռնեք կամ կլոնավորեք այս պահոցը (repository):
3. Գործարկեք `install.bat` ֆայլը (նախընտրելի է ադմինիստրատորի իրավունքով):
4. Տեղադրիչը ինքնուրույն՝
   - Կակտիվացնի Adobe CEP PlayerDebugMode-ը Windows Registry-ում,
   - Ֆայլերը կպատճենի CEP ընդլայնումների թղթապանակում (`%APPDATA%\Adobe\CEP\extensions\CalendarGenerator`),
   - Ֆայլերը կպատճենի UXP պլագինների թղթապանակում (`%APPDATA%\Adobe\UXP\Plugins\External\com.calendar.generator`),
   - Կգրանցի պլագինը InDesign UXP ցանկում (`register_uxp.ps1` սկրիպտի միջոցով):
5. Բացեք Adobe InDesign-ը:

### Տարբերակ 2. Ձեռքով տեղադրում (Manual Installation)

#### CEP ռեժիմի համար.
1. Ակտիվացրեք PlayerDebugMode-ը՝
   - Windows-ում (Registry Editor)` `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` (ինչպես նաև 9, 10, 12 տարբերակներում) ավելացրեք նոր String արժեք `PlayerDebugMode = 1`:
   - macOS-ում (Terminal)` `defaults write com.adobe.CSXS.11 PlayerDebugMode 1`:
2. Պատճենեք նախագծի թղթապանակը համապատասխան ուղղությամբ.
   - Windows՝ `%APPDATA%\Adobe\CEP\extensions\CalendarGenerator`
   - macOS՝ `~/Library/Application Support/Adobe/CEP/extensions/CalendarGenerator`

#### UXP ռեժիմի համար.
1. Պատճենեք ֆայլերը հետևյալ հասցեով՝
   - Windows՝ `%APPDATA%\Adobe\UXP\Plugins\External\com.calendar.generator`
   - macOS՝ `~/Library/Application Support/Adobe/UXP/Plugins/External/com.calendar.generator`
2. InDesign-ում բացեք `Plugins > Plugin Marketplace` կամ օգտագործեք `UXP Developer Tool` (UDT)՝ պլագինը բեռնելու համար:

## Օգտագործման կարգ

1. Բացեք Adobe InDesign-ը և ստեղծեք նոր փաստաթուղթ (կամ բացեք գոյություն ունեցողը):
2. Մենյուից բացեք հավելվածի պատուհանը՝
   - CEP ռեժիմում՝ `Window > Extensions > Օրացույցի Ստեղծիչ`
   - UXP ռեժիմում՝ `Plug-Ins > Օրացույցի Ստեղծիչ`
3. Կարգավորեք պարամետրերը՝
   - Ընտրեք տարեթիվը, լեզուն, տոների երկիրը:
   - Ընտրեք չափսերը (կամ սեղմեք «Վերցնել էջից (Auto)»՝ փաստաթղթի չափսերը կիրառելու համար):
   - Ընտրեք ցանկալի տառատեսակները, տառաչափերը և գույները:
4. Ընտրեք գեներացման եղանակը՝
   - «Գեներացնել 12 ամիսները (12 էջ)»՝ ամբողջական տարեկան օրացույցի համար:
   - «Գեներացնել միայն ընտրված ամիսը»՝ մեկ էջում տվյալ ամիսը ստանալու համար:

## Տեխնոլոգիաներ և ճարտարապետություն

- Օգտագործողի միջերես՝ HTML5, CSS3, JavaScript (ES6+):
- Adobe InDesign ինտեգրացիա՝
  - ExtendScript (JavaScript 1.5 DOM API) CEP աշխատանքի համար:
  - InDesign Scripting API UXP աշխատանքի համար:
  - Պոլիֆիլներ և համատեղելիության շերտեր միաժամանակ երկու հարթակներն անխափան ապահովելու համար:
- Կատարողականության օպտիմալացում՝
  - Զանգվածային փոփոխությունների մեկ գործարքով (single transaction/undo block) կատարում:
  - Էջերի ինտելեկտուալ վերօգտագործում և գեներացման բարձր արագություն:
